# LinkedIn post

I somehow never posted about one of the most useful pages in Number Cruncher: Creative Resizer.

It handles the unglamorous part of creative work:

— drop in multiple images or a ZIP  
— choose 1:1, 4:5, 16:9, 9:16, or exact dimensions  
— adjust the crop for each image  
— set a target file weight in KB  
— click through the batch  
— download every ready file in one ZIP

No upload queue and no bouncing between three different apps. The processing happens locally in the browser, so the selected files stay on your device.

It is intentionally not another design suite. It is a small, fast bridge between a finished creative and every placement, CMS, or ad network that wants its own dimensions and file weight.

Try it here: https://number-cruncher.org/creative-resizer.html
